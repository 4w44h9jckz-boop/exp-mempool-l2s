# 2026-11-04: M12, a relaxed alternative mempool behind the canonical rules

## Done

- **Checked first: can a live node run write-once reads?** No. The Hegota
  testnet's client, ethrex at `64b8fc0`, answers a simulation with a
  verdict and no reads, and its validation observer records any storage
  read outside the sender as `StorageReadNonSender` (`refs/refs.md`,
  2026-11-04). So the write-once module runs in the vector runner only, and
  skandha's node refuses the descriptor at start with that reason
  (decision record 0081).
- **The clause:** `docs/spec/15-relaxed-mempool.md` version 1, RM-1 to
  RM-9, an alternative frame mempool behind the canonical rules, as
  ERC-7562's ALT-020 has it.
  - RM-2: the canonical modules first. The whole descriptor judges only a
    transaction they refuse for a read outside its sender, a busy payer or
    a busy sender, or one with a dependency.
  - RM-3: write-once reads declared per code, any number of readers of a
    set slot and one relaxed reader of an unset one.
  - RM-4: several pending per declared contract on disjoint non-zero keys.
  - RM-5: the non-canonical payer's count lifted for a payer that declares
    an outflow bound, which each relaxed transaction reserves.
  - RM-6: reputation per declared code from each block's EIP-7928 access
    list; RM-7: groups for builders, a lower bound; RM-8: relay, verifier
    and aggregator tiers; RM-9: the bound.
  - `13-descriptors.md` version 5 adds the modules and DS-6 step 6, and the
    fourth descriptor `relaxed.json`, `bafkreihtmp7...k54i`. `00-model.md`
    version 13: a reset takes the blocks' access lists.
- **The vectors,** by hand: eight files in `conformance/vectors/relaxed/`,
  53 cases, one per module and the bound, and the descriptor vectors.
  Before the code, the runner failed on the new modules.
- **The reference,** in `ref/python/emem/framepool/pool.py` and
  `relaxed.py`: 1,120 cases pass, 165 clauses covered. Ten deliberate
  breaks, one per rule, are each caught.
- **skandha** plays all 53 relaxed cases at `bc8687a`: 962 pass, 0 fail.
  Its node refuses `relaxed.json` at start, before the bond it inherits, and
  `--frames.tier` is the node setting, refused at start for any tier but
  `verifier`. Its ten breaks are each caught too.
- **The simulation:** `experiments/27-relaxed-tiers/`, seed 27, at
  `bc8687a`, with a note on its one differing canonical admission at
  `0f48977`. Its
  numbers are in `experiments/27-relaxed-tiers/results.md`:
  - under `relaxed.json` with declarations, no write that breaks no

    one in all; with the relaxations as first asked, one removed 19;
  - each of the 19 writes that break a declaration raised its code's count

    the spends.

## Learned

- **The relaxations as first asked do not keep the bound.** Read against
  FP-10, FP-11 and FP-15, several pending per sender and the payer's count
  lifted each let one write invalidate many: a delegation, a sender slot,
  or a payment the pool does not hold. Decision record 0082 bounds them
  with a declared contract and a reserve, and experiment 27 measures both.
- **A violation shows in the access list, not the state.** A second write
  to an unset slot within a block leaves the state looking like a first
  write; only EIP-7928's per-transaction changes show two.
- **Two vector cases passed with a rule broken,** shown by porting them to
  skandha. They were tightened before publishing, in `833b5ec`.

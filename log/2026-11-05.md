## Learned

- **The first relay vector did not catch a broken relay.** A wrapper's
  transaction is never relayed by construction, so the rule showed only
  when a proven transaction later came over `eth_sendRawTransaction`. The
  case now sends a replacement that way.
- **Under gossipsub, "accept" is a relay.** SF-6's new rule needed a row in
  SF-7's table, or a peer's copy would be forwarded by the mesh.
- **Experiment 19's prover has no `verify-sphincs` at `47f5496` or
  `d3edeb9`.** An unknown mode falls through to its program path and exits
  non-zero, so a node naming it refuses every wrapper with a dependency
  until the mode lands. Its signatures are 7,740 bytes (`claims_of`).
